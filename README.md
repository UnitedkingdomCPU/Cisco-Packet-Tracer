# Cisco-Packet-Tracer
Масштабный проект корпоративной инфраструктуры, реализованный в Cisco Packet Tracer.
Этот репозиторий содержит детальную модель распределенной корпоративной сети для офиса на 200+ сотрудников. Проект демонстрирует навыки проектирования, настройки и администрирования современных LAN/WAN сетей, серверной инфраструктуры, IP-телефонии и IoT-решений.
